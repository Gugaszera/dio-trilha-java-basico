# DesafioControleFluxo

Programa que lê dois números inteiros e imprime os números de 1 até a diferença entre eles.

## Executar

Na pasta `DesafioControleFluxo`, com um JDK instalado:

```bash
javac Contador.java ParametrosInvalidosException.java
java Contador
```

Para as entradas `12` e `30`, serão impressas 18 linhas. Se o primeiro número for maior, será exibida a mensagem `O segundo parâmetro deve ser maior que o primeiro`.
